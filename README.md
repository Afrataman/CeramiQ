# CeramiQ Web Demo

CeramiQ Web Demo is the browser-based demonstration version of a production management system designed for ceramic factories.

[Open the live demo](https://afrataman.github.io/CeramiQ/)

> This repository contains the HTML, CSS and JavaScript demo.  
> The ASP.NET Core MVC and SQL Server version is available in the [CeramiQ ERP repository](https://github.com/Afrataman/CeramiQ-ERP).

## Features

- Product and stock monitoring
- Production order tracking
- Scrap record management
- Critical stock warnings
- Delayed production warnings
- High scrap rate warnings
- Operational alert explanations
- CSV report export
- Browser-based storage with localStorage

## Technologies

- HTML
- CSS
- JavaScript
- Bootstrap
- Chart.js
- GitHub Pages
